# Swiftboard sample apps

Every folder is a separate SwiftUI app. Open https://swiftboard.spiritt.app/ and use
"Open project folder" (or drag the folder onto the board). Each #Preview becomes a live frame.

01-Messenger       Telegram-style messenger: 5 files, 5 previews (chat list, chat, contacts, calls, settings)
02-Weather         gradient weather screen, °C/°F toggle
03-TodoPlayground  counter, toggle, filters, add todos (same as "New blank app")
04-Calculator      working iOS-style calculator (try 7 × 6 =)
05-MusicPlayer     library list + floating mini player
06-Notes           searchable notes, push to detail, quick add
07-Shop            product grid, add to cart, tab badge, cart total

Tip: drop several folders at once and each one gets its own frames on the board.
