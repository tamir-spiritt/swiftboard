How it works

Real Swift. Each frame runs the app's SwiftUI source, interpreted by a Rust engine compiled to WebAssembly. No simulator, no Mac.

Click around. Frames are live: tap chats, type, send, switch tabs, scroll.

Select elements to restyle; edits are written back into the Swift code.

Copy + paste a frame to fork the whole codebase. Each branch evolves on its own.
